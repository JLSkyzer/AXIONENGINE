# tools/

| Dossier | Rôle |
|---|---|
| `ci/` | la CI locale (`local_ci.py`) et ses contrôles |
| `spec/` | les index du cahier des charges (`spec_index.py`) et des ADR (`adr_index.py`) |
| `film/` | l'encodage des films en MP4 (`encoder.py`) |
| `bench/` | le lancement et la comparaison des benchmarks |
| `campagne/` | la campagne sur serveur de production (journal latéral) |
| `codegen/` | la génération de code partagée entre Rust et Java |
| `assets/` | la production de modèles d'essai |
| `gametest/` | les structures des GameTests |
| `ffi/` | la vérification des exports de la bibliothèque native |
| `deps/` | la génération du fichier `NOTICE` |
