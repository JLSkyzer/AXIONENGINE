# ADR-136 — Écart à la table 32.2 : `serde_json` lit les options de compilation dans le runtime

- **Statut** : **accepté** — écart tranché par Killian le 2026-10-14.
- **Date** : 2026-10-14
- **Portée** : table 32.2 (« Écarté : `serde_json` en runtime jeu ») ; ADR-135 (options de
  compilation) ; `ax-asset` (`ax_asset::options`)
- **Proposé par** : Claude, après avoir constaté l'écart ; **tranché par** : Killian le 2026-10-14

## Contexte

La table 32.2 écarte « `serde_json` en runtime jeu », au motif que « le JSON est parsé côté Java
par Gson, déjà présent ».

L'ADR-135 (point 1, Killian) fait passer le texte du `<modèle>.axion.json` au natif, qui
l'interprète par **un seul lecteur**, celui qu'emploie aussi `axion-cli` : l'identité de R-830 tient
par construction. Le commit 3464a16 a écrit ce lecteur sur le tokeniseur de `serde_json`, devenu
dépendance directe d'`ax-asset`, crate lié à la bibliothèque native. La table 32.2 n'avait pas été
relue : l'écart a été vu après coup, le 2026-10-13.

`serde_json` était déjà lié à la bibliothèque native avant ce commit, de façon transitive : `gltf`
et `gltf-json`, retenus par la même table, s'en servent pour lire les glTF (`cargo tree -p ax-ffi -i
serde_json`).

Comme pour l'ADR-105, le cahier des charges est gelé : la table 32.2 n'est pas corrigée, l'écart
est consigné ici.

## Décision

**L'écart est accepté, et borné.**

- Dans le runtime, `serde_json` ne sert **qu'au lecteur d'options** de la PARTIE 6.4
  (`ax_asset::options`) : son tokeniseur, et un visiteur propre qui refuse ce que `serde_json::Value`
  laisserait passer (clé en double).
- Tout autre JSON lu par le jeu — definitions, configuration, données des packs — reste lu côté Java
  par Gson, comme la table 32.2 le veut.
- Le binaire ne gagne aucune dépendance : celle-ci y était déjà, par `gltf`.

## Conséquences

- La table 32.2 reste la règle ; cet ADR en est une exception nommée. Une autre lecture JSON dans le
  runtime demande un nouvel ADR.
- Avant d'ajouter une dépendance à un crate du runtime, la table 32.2 se relit en entier, y compris
  la liste de ce qu'elle écarte (`tasks/lessons.md`, 2026-10-14).
